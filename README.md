### Project Description / Goal

This project aims to use machine learning to predict whether a student reports experiencing depression based on demographic, academic, social, and health-related information.

The dataset contains survey responses from students, and we will investigate which factors may be useful for predicting depression among students.

Our goal is to train and compare multiple machine learning classification models and evaluate their performance using accuracy, precision, recall, and F1-score.

### Data Source and Collection Method

The dataset, Student Depression Dataset was obtained from https://data.mendeley.com/datasets/xn9cb5zpgg/2

The data was collected through a survey using google forms. The participants were students between the ages of 17-28.
